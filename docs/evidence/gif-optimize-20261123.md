## 2026-11-25 透明與近上限樣本複驗

- 使用 Rust 1.100.0 release WASM 與 SPA 正式建置，在 Windows x64、Intel i7-12700KF、Chromium Headless 159.0.8154.6、Node 24.22.1 驗證。Pillow 12.3.0 建立及解碼合成樣本。桌面與 375 px 手機視窗皆完成選檔及下載，未觀察到對外請求或頁面例外。

## 回復步驟

若正式環境無法處理 GIF 或其他工具出現回歸，將本 PR 在 `main` 的合併提交透過回復 PR 反轉。合併回復 PR 後確認 Pages 的 build 與 deploy 成功，再以公開頁驗證 GIF 入口回到合併前狀態，並以合成圖片確認既有圖片工具可下載結果。
