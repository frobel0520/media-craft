# Favicon 與 PWA 圖示驗收

2026-11-23，Harbor 任務 `7954fc6c`。本機 Windows x64、Node 24.22.1、Headless Chromium，從預建 SPA 讀取檔案。合成來源為 128 × 64 透明 PNG。圖示等比例置中，輸出名稱固定。

- 1280 × 800 與 375 × 812 都能從側欄開啟工具、選擇圖片及下載 ZIP。兩份 ZIP 均含可解碼的 32 × 32 ICO、192 × 192 及 512 × 512 PNG，透明邊緣與不透明中心皆由 Pillow 讀回驗證。
- 兩種寬度皆無水平溢位，選檔按鈕高至少 38 px，未觀察到第三方請求、CSP 違規或頁面例外。
- 圖示產生 p50 31.7 ms、p95 47.8 ms（兩種寬度各 10 次，共 20 次，首筆含 Worker 首次處理、其餘為暖啟動；從注入合成選檔到下載按鈕就緒）。低於本機合成樣本的 1 秒 p95 門檻。
- `npm run build` 通過。實體手機及正式部署效能仍待驗。
