# 圖片工作台編輯與批次控制驗收（2026-11-23）

分支 `feature/20261123-image-edit-batch`。範圍：置中裁切、90° 旋轉、水平／垂直翻轉、自訂輸出檔名、批次進度與取消；HEIC 只做評估。

## 環境

- 本機 `npm run dev`（Vite 7）＋ Claude 桌面版內建 Chromium 瀏覽器窗格；WASM 使用正式站目前的 `media_wasm.wasm`（本機無 Rust 工具鏈，本次未改 Rust）。
- 測試圖由頁面內 `OffscreenCanvas` 合成：四個象限分別為紅（左上）、綠（右上）、藍（左下）、黃（右下）的 PNG，沒有真實照片。
- 透過真實 UI 操作（檔案選取器 `change`、按鈕 `click`、下拉選單 `change`），輸出從畫面上的 `<img>` 讀回像素；不是直接呼叫函式。

- 4000×2000 + 最大寬度 800 + 右轉 90° → 800×1600（寬度上限套用在旋轉後的輸出）。
- 4000×2000 + ICO + 右轉 90° → 128×256（ICO 256 上限仍有效）。

### 檔名規則

- 範本 `trip-{n}-{w}x{h}`，12 張 3000×2000 → `trip-01-3000x2000.webp` … `trip-12-3000x2000.webp`（序號補零到佇列位數）。
- 不合法字元 `a/b:c*?"<>|same` → `a_b_c______same.webp`；空白範本退回原檔名（`x.webp`）。
- 三張都命名 `same` 再打包 ZIP → `same.webp`、`same-2.webp`、`same-3.webp`。
- 切到「純無損去 EXIF」時，若範本仍是預設值會自動換成 `{name}-clean`；切回來還原 `{name}-craft`，使用者自訂的範本不被覆蓋。輸出 `raw-clean.png`。

### 批次進度、取消與重試

- 12 張 3000×2000 PNG → WebP：進度依序顯示 `0 / 12` → `1 / 12` → …，`role="progressbar"` 的 `aria-valuenow` 同步。
- 第 3 張完成後按「取消批次」：完成手上那張後停止，顯示「已取消：完成 4 / 12」，4 張完成、8 張保留在佇列（閒置狀態）。
- 按「重新處理全部（12）」→「批次完成：12 / 12」。
- 批次進行中，「清空」、單張「處理」與 ZIP 按鈕停用，避免同時送出。

### 原有功能

- ZIP：12 個檔案全部打包，central directory 名稱與單張輸出一致，下載檔名 `media-craft-batch.zip`。
- 純無損去 EXIF 流程仍可輸出；編輯控制項在此模式隱藏（無損模式不改像素）。
- `npm run typecheck` 與 `npm run build` 通過。

### 版面（UI）

- 桌面寬度與 375×812 手機模擬：水平溢位 0；編輯按鈕與佇列按鈕高度 ≥ 44px；控制區最小字級 12px。
- 翻轉按鈕以 `aria-pressed` 與強調色標示開啟狀態。

## HEIC 按需載入評估（不在本單導入）

| 選項 | npm 版本／授權 | 套件解壓大小 | 評估 |
|---|---|---|---|
| 瀏覽器原生解碼 | — | 0 | 只有 Safari（macOS／iOS 17 以後）能解 HEIC；Chrome、Edge、Firefox 不能。可先用 `createImageBitmap` 偵測，支援就直接用。 |
| `heic2any` | 0.0.4／MIT | 約 2.7 MB | 內含 libheif，2023 年後未更新，維護風險高。 |
| `libheif-js` | 1.23.5／LGPL-3.0 | 約 9.0 MB（含多種建置） | 持續維護；LGPL 需保留授權與可替換性，只能動態載入、不併入主 bundle。 |
| `heic-to` | 1.6.7／LGPL-3.0 | 約 26 MB | 體積過大，不建議。 |

建議：下一階段用「Safari 原生解碼優先＋其他瀏覽器在選到 `.heic` 時才動態 `import()` libheif-js 的 WASM 建置」。導入前要先量實際下載體積（預估 1 MB 以上，未實測）、確認 HEVC 專利與 LGPL 授權公告位置，並依 `docs/03-system-design.md` 記錄評估。上表大小取自 2026-11-23 的 npm registry metadata，不是實際 bundle 大小。

## 未驗證

- 正式站部署後的效能與標頭。
